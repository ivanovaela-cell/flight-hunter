# ✈️ Flight Hunter v1.0

> Автономная система мониторинга авиабилетов и предварительного обнаружения выгодных тарифов с мгновенным переходом к Live-верификации и покупке.

Программа разработана для личного использования (поиск билетов на двухмесячное путешествие по Азии и любые будущие поездки по миру) и работает по **двухэтапной схеме**:
1. **Этап A (Автоматическое обнаружение):** фоновый мониторинг через Travelpayouts Data API v3 (бесплатно, по расписанию, без капч и скрейпинга).
2. **Этап B (Проверка перед покупкой):** мгновенная генерация точной ссылки на живой поиск Aviasales с предзаполненными параметрами (город, даты, класс обслуживания, количество пассажиров) для проверки свободных мест, окончательной цены и включенного багажа.

---

## 🌟 Основные возможности

* **Любой класс обслуживания:** Бизнес, Эконом, Премиум-эконом, Первый класс или «Любой» для сопоставления тарифов.
* **Произвольная география:** Поддержка любых аэропортов, городов и стран мира (IATA коды: MOW, BKK, CAN, HAN, DPS, DXB, IST и др.).
* **Многосегментные путешествия:** Возможность одновременно мониторить дальний перелет бизнес-классом (Москва ➔ Китай/Таиланд) и несколько коротких перелетов экономом внутри Азии.
* **Фильтрация авиакомпаний:** Поддержка предпочитаемых и исключенных перевозчиков.
* **Строгий контроль багажа и сборов:** Все расчетные цены за нескольких пассажиров явно маркируются как `ESTIMATED`, а отсутствующая норма багажа — как `BAGGAGE_UNKNOWN` (никаких вымышленных норм).
* **Локальный веб-интерфейс на русском языке:** Управление поисковыми заданиями (создание, редактирование, копирование, пауза, ручной запуск), таблица билетов с кнопкой «Проверить цену и купить», история цен и статус системы.
* **Telegram-уведомления:** Бот с белым списком Chat ID (оповещения при ценах ниже бюджета, новых исторических минимумах и снижении цены от 15%).
* **Персистентность SQLite:** Вся история, профили и кэш хранятся в `data/flights.db` и сохраняются при перезапуске.

## 🚀 Быстрый запуск на Windows

### 1. Требования
* Node.js v22+ или v24 LTS (установлен в системе).

### 2. Настройка окружения
В файле `.env` в корне проекта уже настроен ваш рабочий токен Travelpayouts.
При желании подключить Telegram добавьте:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
TELEGRAM_CHAT_ID=ваш_chat_id_от_userinfobot
WEB_PORT=3000
POLL_INTERVAL_HOURS=2
```

### 3. Запуск веб-интерфейса и службы мониторинга
```powershell
npm start
```
После запуска откройте браузер:
👉 **http://localhost:3000**

## 🛠️ Доступные команды

| Команда | Описание |
| :--- | :--- |
| `npm start` | Запуск постоянной службы: веб-сервер (порт 3000), фоновый планировщик и Telegram-бот |
| `npm run scan` | Однократный опрос всех активных заданий с выводом результатов в консоль и сохранением в SQLite |
| `npm test` | Запуск автоматизированного тестового пакета (проверка всех 15 критериев приемки) |

## 🤖 Команды Telegram-бота

Если в `.env` указаны `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, бот доступен для управления:
* `/start` — Информация о боте и проверка прав доступа (белый список).
* `/search` — Принудительный запуск сканирования всех направлений прямо сейчас.
* `/top` — ТОП-10 самых выгодных предложений из базы данных.
* `/daily` — Краткая суточная сводка минимальных тарифов по активным заданиям.
* `/status` — Состояние планировщика, базы данных и счетчик запросов.

## 🐳 Развертывание на Linux VPS (Docker)

Для будущего переноса на сервер подготовлены `Dockerfile` и `docker-compose.yml`:

```bash
# 1. Склонировать папку на VPS
# 2. Убедиться в наличии файла .env
# 3. Запустить контейнер в фоне:
docker compose up -d --build

# 4. Просмотр логов:
docker compose logs -f
```

База данных SQLite монтируется в том `./data`, гарантируя сохранность истории при обновлениях контейнера.
